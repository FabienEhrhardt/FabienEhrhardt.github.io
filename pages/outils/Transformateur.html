ℹ️ Aide et conventions

• Les trois appareils d'entrée mesurent U1, I1 et P1 (puissance active absorbée) ; ceux de sortie U2, I2 et P2 (puissance active fournie à la charge). Valeurs efficaces.
• Essai à vide : secondaire ouvert. Court-circuit : secondaire en court-circuit ; le variac est remis à 0 et il faut monter U1 progressivement (le relais thermique protège le transformateur).
• Pour la charge Z ∠ φ : φ > 0 charge inductive (le courant retarde sur la tension), φ < 0 charge capacitive.
• Sur l'oscilloscope, la phase de u1 est la référence. Pour mesurer un déphasage : φ = 360 × f × Δt.
• Les onglets « Modélisation » et « Bilan de puissance » servent à interpréter et vérifier vos mesures.

Modèle de Kapp — pertes Joule ramenées au secondaire
Équations du modèle
Primaire à vide : IR = U1/Rf ; ILm = U1/(Lm·ω) ; P0 = Pfer = U1²/Rf ; Q0 = U1²/(Lm·ω)
Tension secondaire : U20 = m·U1 ; ΔU ≈ Rs·I2·cos φ2 + Xs·I2·sin φ2
Puissances : P1 = Pfer + PJ + P2 avec PJ = Rs·I2² et P2 = U2·I2·cos φ2
Comment utiliser les essais pour déterminer les éléments du modèle ?
Essai à vide (U1 = U1n) : m = U20/U1 ; Rf = U1²/P0 ; Lm·ω = U1²/Q0 avec Q0 = √((U1·I10)² − P0²)
Essai en court-circuit (I2 = I2n) : Rs = Pcc/I2cc² ; Zs = U2cc/I2cc (avec U2cc = m·U1cc) ; Xs = √(Zs² − Rs²)
Les pertes fer sont négligeables en court-circuit (U1 faible) ; les pertes Joule sont négligeables à vide (I2 = 0).
